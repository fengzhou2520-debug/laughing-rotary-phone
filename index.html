Technical summary

Realtime LIF kernel (1 ms steps) on the full Male CNS CSR graph (165,122 neurons · 25,563,197 synapses). Every neuron is integrated each step; every synapse from every spike is delivered. Sugar stimulates only gustatory receptors — motor pools are recruited by network propagation. Parameters inspired by Shiu et al., Nature 2024 and the embodiment pattern of infinite-sugar. Body: FlyBody via MuJoCo WASM + three.js. No learning or habituation.
